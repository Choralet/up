# iPhone test pass (about 15 minutes)

Open https://choralet.github.io/up/ in **Safari** → Share → **Add to Home Screen**, then open **Up** from the home screen. Tick each line; for anything wrong, note what you saw (a screenshot helps) and send it back.

## 1. Look and feel
- [ ] Status bar (clock, battery) readable in light mode and in dark mode (Settings app → Display & Brightness).
- [ ] Sheets slide up, screens slide in, ticks pop, the rep number rolls. Nothing feels slow or jumpy.
- [ ] Settings app → Accessibility → Motion → **Reduce Motion** on: animations stop. (Turn it back off.)
- [ ] Settings app → Accessibility → Display & Text Size → **Larger Text**: nothing overlaps or gets cut off.

## 2. A workout
- [ ] Today shows the day's exercises by track and a core finisher.
- [ ] Log a few sets; tap a set chip to fix it; double-tap Log Set logs only one set.
- [ ] A hold (dead hang or plank): Start → 3-2-1 → the whole screen stops it. With **Sound at Hold Goal** on and the ring/silent switch **off**, a soft tone plays at the goal.
- [ ] The screen stays on during a hold (don't touch the phone for 40 s).
- [ ] Reach a goal → level-up sheet → Level Up → open Tree: the new exercise lights up.
- [ ] Finish Workout shows the summary.

## 3. Progress and history
- [ ] Progress: week strip, achievements grid, recent sessions.
- [ ] An exercise's **History** shows the chart; tap a dot for its value.

## 4. Tree
- [ ] Pinch to zoom the tree; − / + / % buttons work; chips open the exercise.

## 5. Settings
- [ ] Workout Length Short / Standard / Full changes Today.
- [ ] **Add Reminders to Calendar** opens a calendar file you can add to Apple Calendar; an alert appears at the time you picked.
- [ ] **Export Backup File** opens the share sheet; save it to Files.
- [ ] GitHub backup: connect (see docs/BACKUP.md), Back Up Now shows "Last backup".

## 6. Offline and reopen
- [ ] Turn on Airplane Mode, close Up fully, reopen: it still opens and your data is there.
- [ ] Leave Up in the background overnight: next morning Today shows the new day.

## 7. Game Quest redesign
- [ ] Open Up online once, then turn on Airplane Mode and reopen: the rounded font still shows.
- [ ] Log the last set of an exercise: the level-up card shows the badge bounce and the bar filling. Finish Workout counts its totals up.
- [ ] Settings → Accessibility → Motion → Reduce Motion on: the same screens show their final state with no movement.
- [ ] Switch the phone between light and dark mode: every screen is readable in both.
- [ ] Settings → Display & Brightness → Text Size larger: Legs + Core day header still fits.

## 8. New tree data (Plan 8)
- [ ] Your old progress is still there (Today shows where you were; Tree shows your finished exercises).
- [ ] Settings → **My Equipment**: tick Pull-up bar and Bands. Today only offers exercises you can do; greyed ones in the Tree say what they need.
- [ ] Tree: Push / Pull / Legs / Core, then the ladder chips (Push-ups, Overhead, Dips, Handstand…). Each ladder fits or scrolls sideways.
- [ ] Tap an exercise: Move on when, Equipment, Muscles, Source and How-to links open in Safari.
- [ ] Workout Length **Full** adds an Accessory (a different one next week).

## 9. Full body and rest (Plan 9)
- [ ] Today on a training day says "Full Body Day", Session A or B, about how many minutes, and shows Pair 1–3 plus Core.
- [ ] Log a set: a rest countdown appears under Log Set; Skip hides it. Settings → Rest Timer off stops it.
- [ ] With only a band and a bar ticked, Dips says what it needs instead of showing a too-hard dip.
- [ ] Settings → Weekly Plan switches to Push / Pull / Legs and back, keeping your days.

## 10. VoiceOver (optional)
- [ ] Settings → Accessibility → VoiceOver on: swipe through Today and a log screen; buttons and numbers are read sensibly.
