Up: design mockups

Static mockups for approval (v2: the skill tree is now a real branching tree). Apple-like: system font, SF-style rounded cards, big numbers, one accent per branch, quiet celebrations. Switch light and dark below. Built as a web app with our own Apple-style CSS.

App name: Up (chosen). Runs as a web app on the iPhone home screen. New: a small How-to button (screens 2, 3, 5) opens a form demo (screen 9), shown only when a demo exists.

Notes: the rings are our own style, not Apple's official Activity rings (Apple's guidelines say not to recolor those). Branch colors: Push orange, Pull blue, Legs green, Core purple, Skills pink. Exercise names and numbers are sample data.
