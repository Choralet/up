# Skill Progressions (draft data)

Researched 2026-09-26 from [Gymnase Tips](https://www.gymnasetips.com/calisthenics-skills/), [Calisteniapp](https://calisteniapp.com/articles/order-calisthenics-tricks) and [Simple Calisthenics](https://www.simple-calisthenics.com/features/calisthenics-skill-tree).
**Treat every number as a starting default.** Sources differ and are not peer-reviewed. Goals are editable in the app, and the bundled JSON is the single source.

## How skills differ from regular strength chains

| | Strength chain (Push/Pull/Legs/Core) | Skill (e.g. Handstand) |
|---|---|---|
| Goal type | Reps (3×10) or hold | Mostly **holds** (seconds) or few quality reps |
| Where in workout | Main work | **First block after warm-up**, when fresh |
| Volume | 3 sets | 4–8 short sets, stop before fatigue |
| Speed | Weeks per step | **Months per step** |
| Unlock | Suggestion when goal met | Same suggestion, plus soft "recommended before starting" strength check |

Skills are **soft-gated**: the app shows "Recommended: 10 pull-ups + 15 dips before Muscle-up" but never blocks you.

> In the app these chains become **branches of the main tree** (see PLAN.md section 3b). Steps listed in order below are the main path. Some steps can have alternatives or extra parents.

## Skill lists (steps in order)

**Handstand** (Push day): Chest-to-wall hold (60 s) → Back-to-wall hold (60 s) → Wall walks (3×5) → Kick-up practice → Freestanding hold (1–5 s → 30 s)
**Handstand push-up** (Push day): Pike push-up → Feet-elevated pike → Wall HSPU partial → half → full → Freestanding HSPU
**Planche** (Push day): Planche lean → Tuck planche (5–10 s) → Advanced tuck (10–15 s) → Single-leg → Straddle (5 s) → Full (3 s)
**One-arm push-up** (Push day): Archer → Uneven → One-arm feet wide → shoulder-width → feet together
**Muscle-up** (Pull day): High pull-up → Explosive pull-up → Negative muscle-up → Kipping → False-grip strict → Strict muscle-up
**Front lever** (Pull day): Tuck (10–15 s) → Advanced tuck (8–12 s) → Single-leg (6–10 s) → Straddle → Full (5 s)
**Back lever** (Pull day): Skin-the-cat → German hang → Tuck → Advanced tuck → Single-leg → Straddle → Full (5 s)
**One-arm pull-up** (Pull day): Weighted pull-up → Archer → Typewriter → Assisted one-arm → Negative → Full
**L-sit** (Legs + Core day): Tuck L-sit → Single-leg → Bent-knee → Full (15 s) → V-sit
**Dragon flag** (Legs + Core day): Hanging knee raise (15) → Hanging leg raise (10) → Tuck dragon flag → Single-leg → Negative → Full (5)
**Pistol squat** (Legs + Core day): Box pistol → Heel-elevated → Counterweighted → Assisted → Negative → Full (5/side)
**Human flag** (Pull day, advanced): Vertical pole hold → Chamber flag → Single-leg → Straddle → Full

## Realistic timelines (set expectations in the app)

- Foundational (handstand basics, L-sit, pistol): about 3–6 months
- Intermediate (muscle-up, front/back lever, dragon flag): about 6–18 months
- Advanced (planche, human flag, one-arm pull/push-up): 1–4 years

Sources agree that people usually learn **muscle-up first** and planche/front lever later.

## Recommended prerequisites (soft)

- Muscle-up: about 10+ pull-ups and 15–20 dips
- Planche/front lever: solid pull-up/dip base, then hold lean/tuck steps
- Handstand: comfortable push-ups (20+) and pike push-ups

## Rule: max 2 active skills at once

Skill work is neurologically taxing. The app lets you pick 1–2 skills and assigns each to its matching day (see PLAN.md, section 5).
